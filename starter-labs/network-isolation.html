Part 2 · Protect Mercy General Hospital

Mercy General Hospital has six security problems. You are the network security lead. Match each problem with the isolation technique that solves it best, and write one sentence explaining why. Then press Test my design to send real traffic at your network.

  • Use each technique exactly once.
  • You can test as many times as you need. A problem you solve locks in.
  • Each miss lowers what that problem is worth, so think before you test.

Each problem is worth 20 points if solved on the first try, then 15, 10, and 5 after that.
